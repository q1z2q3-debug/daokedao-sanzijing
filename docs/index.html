三字经

一句原文　一个真故事　一段白话　一条成长启示
三

一课一句，一句两页。左页给孩子读——大字、田字格、水墨小画；右页给大人读——字义、出处、中西对照、存疑。同一册书，两种深度。孩子读到画面与故事，大人读到义理与分寸。
